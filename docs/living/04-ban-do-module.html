AEGIS–Vanguard

AI điều phối tool qua MCP; sandbox thực thi; metadata, tri thức quan hệ và raw được lưu riêng.

Mục tiêu → AI lập kế hoạch → MCP → queue/dependency/priority → sandbox → collector/ingestion → S3 + metadata + graph → UI và agent đọc kết quả

AI agent

Chọn tool và input, lập dependency/priority, đọc tri thức và tiếp tục. LangGraph + ModelClient.

MCP

Registry/schema, tool calls và graph/evidence queries. Adapter bọc CLI chạy trong sandbox.

Điều phối

Temporal quản lý queue, timer, retry, pause/resume/cancel và ngân sách. Dependency đạt trước khi xét priority.

Sandbox

Podman rootless; mỗi job một container. Giới hạn CPU/RAM/timeout, cách ly mạng và filesystem.

Metadata

PostgreSQL: campaign, job, trạng thái, audit, cấu hình, finding và tham chiếu raw.

Graph tri thức

Neo4j: asset, quan hệ và nguồn gốc. Bản chiếu dựng lại từ metadata.

S3 raw

SeaweedFS qua S3: output gốc, log, artifact và checksum. Collector tải lên, tool chỉ ghi /out.

Ingestion

Kiểm schema, provenance, hash và dedup; chuẩn hóa kết quả rồi chiếu graph.

Giao diện

Campaign, kế hoạch/job, graph, finding và evidence. SSE cập nhật trạng thái và lý do chờ.

Tool cụ thể được thêm bằng manifest, schema và parser. Repo hiện là thiết kế/contract; các khối trên chưa phải dịch vụ đã triển khai.
